## 📖 Sobre o Projeto

O **Solar Explorer** é um projeto front-end que simula o sistema solar de forma visual e interativa.  
Os planetas possuem animações de rotação contínua e podem ser selecionados para exibir informações detalhadas em um painel lateral.

O foco do projeto é unir **design moderno**, **animações suaves** e **interatividade**, criando uma experiência imersiva para o usuário.

---

## ✨ Funcionalidades

- 🌍 Visualização dos planetas do sistema solar  
- 🔄 Animação de rotação realista  
- 📚 Exibição de descrições detalhadas  
- 🎯 Menu interativo para seleção dos planetas  
- 🎨 Interface moderna com efeitos visuais  
- 📱 Layout adaptado para diferentes telas  

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** → Estrutura da aplicação  
- **CSS3** → Estilização, animações e efeitos visuais  
- **JavaScript** → Interatividade e manipulação do DOM
